# Key Terms

| Key Terms       | Description                                                                                         |
| --------------- | --------------------------------------------------------------------------------------------------- |
| Period (T)      | Time taken for a complete oscillation                                                               |
| Amplitude (A)   | Maximum displacement of the bob from its<br>equilibrium position.                                   |
| Frequency (f)   | Number of oscillations completed per unit time.<br><br>$\text{frequency} = \frac{1}{\text{period}}$ |
| Length ($\ell$) | The distance from the pivot to the centre of the<br>bob.                                            |

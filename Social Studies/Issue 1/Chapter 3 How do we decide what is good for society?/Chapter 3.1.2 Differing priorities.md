# Definition 
- It is challenging to decide which needs and interests are to be addressed, as there are differing priorities among people and limited resources
# Examples
| Case Study           | Examples                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Using a plot of land | Singapore is a land scarce country, so it is crucial that land use is optimised so that it fulfils current and future needs of the people. On a plot of land, only one thing can be built. For example, elderly living in the area who have medical needs would like a hospital to be built. However, citizens in the same area with school-going children would prefer a school to be built |

# How it works
- Parity bit controls total number of 1 bits, as it decides whether it is even or odd
# Odd parity
- Total number of 1 bits add up to odd number
# Even parity
- Total number of 1 bits add up to even number
# Limitations
- If two bits are changed, then it could turn it into the original parity, so data may be corrupted but not detected

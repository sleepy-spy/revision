
| Layer           | Purpose                                                                                                                                                                                                                                           |
| :-------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Physical     | The lowest layer of the OSI Model is concerned with<br>electrically or optically transmitting raw unstructured<br>data bits across the network from the physical layer of<br>the sending device to the physical layer of the receiving<br>device. |
| 2. Data Link    | At the data link layer, directly connected nodes are used<br>to perform node-to-node data transfer where data is<br>packaged into frames.                                                                                                         |
| 3. Network      | The network layer is responsible for receiving frames<br>from the data link layer, and delivering them to their<br>intended destinations based on the addresses contained<br>inside the frame.                                                    |
| 4. Transport    | The transport layer manages the delivery and error<br>checking of data packets. It regulates the size,<br>sequencing, and ultimately the transfer of data between<br>systems and hosts.                                                           |
| 5. Session      | The session layer controls the conversations between<br>different computers.                                                                                                                                                                      |
| 6. Presentation | The presentation layer formats or translates data for the<br>application layer based on the syntax or semantics that<br>the application accepts.                                                                                                  |
| 7. Application  | At this layer, both the end user and the application layer<br>interact directly with the software application.                                                                                                                                    |

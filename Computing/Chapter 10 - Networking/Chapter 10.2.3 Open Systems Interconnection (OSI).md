# TCP/IP - Transmission Control Protocol/Internet Protocol
- Organises how data packets are communicated and makes sure packets have:
	- source - which computer the message came from
	- destination - where the message should go
	- packet sequence - the order the message data should be er-assembled
	- data - the data of the message
	- error check - the check to see that the message has been sent correctly
# UDP - User Datagram Protocol
- Communications protocol primarily used to establish low-latency and loss-tolerating connections between applications on the internet.

# HTTP - Hypertext Transfer Protocol
- Transfer web pages from web servers to the client
# FTP - File Transfer Protocol
- A way to download, upload and transfer files from one locations to another on the INternet and between computer systems
# ARP -  Address Resolution Protocol
- ARP is a protocol or procedure that ocnnects an ever-changing Internet Protocol (IP) address to a fixed physial machine address, also know as a media access control (MAC) address.
# SMTP - Simple Mail Transfer Protocol
- An internet communication protocol for electronic mail transmission over a network to a mail server
# IMAP/POP3 - Internet Message Access Protocol/Post Office Protocol
- Internet standard protocol used by email clients to retrieve email messages from a mail server over a TCP/IP connection. 
- POP3 is an older protocol

## Displacement, Velocity and Acceleration
$$\mathrm{Displacement} = \Delta\vec{r}$$
$$\mathrm{Average\ Velocity} = v_{\mathrm{average}} = \frac{\Delta \vec{r}}{\Delta t}$$
$$\mathrm{Instantaneous\ Velocity} = v_{\mathrm{instant}} = \frac{\mathrm{d}\vec{r}}{\mathrm{d}t}$$
$$\mathrm{Average\ Acceleration} = a_{\mathrm{average}} = \frac{\Delta \vec{v}}{\Delta t}$$
$$\mathrm{Instantaneous\ Acceleration} = a_{\mathrm{instant}} = \frac{\mathrm{d}\vec{v}}{\mathrm{d}t} = \frac{\mathrm{d}^2\vec{r}}{\mathrm{d}t^2}$$
$$\text{Remember\ that\ r\ and\ v\ are\ vectors,\ so\ consider\ their\ components\ if\ 2D\ and\ above}$$

## Kinematics Equations with Constant Acceleration (SVTA)
$$\vec{v} = \vec{u} + \vec{a}t \tag{1}$$
$$\Delta\vec{r} = \vec{u}t + \frac{1}{2}\vec{a}t^2 \tag{2}$$
$$v^2 = u^2 + 2\vec{a}\cdot\Delta\vec{r} \tag{3}$$
$$\Delta\vec{r} = (\frac{\vec{v} + \vec{u}}{2})t \tag{4}$$
### Projectile Motion
$$\mathrm{Consider\ horizontal\ and\ vertical\ components\ separately}$$
$$a_{y} = -g\ \mathrm{and}\ a_{x} = 0$$
$$\mathrm{Plug\ into\ kinematics\ equations\ and\ solve\ accordingly}$$

## Uniform Circular Motion
$$\mathrm{Centripetal\ Acceleration = a_{\mathrm{rad}} = \frac{v^2}{r}}$$
$$\mathrm{Since\ v = \frac{2\pi r}{T}}$$
$$a_{\mathrm{rad}} = \frac{4\pi^2r}{T^2}$$
## Relative Velocity
$$\mathrm{If\ P\ is\ relative\ to\ B,\ and\ B\ is\ relative\ to\ A,\ then\ P\ relative\ to\ A\ is}$$
$$\vec{v}_{P/A} = \vec{v}_{P/B} + \vec{v}_{B/A}$$

$$\mathrm{In\ 2D\ and\ above,\ remember\ that\ v\ is\ a\ vector,\ and\ regular\ addition\ fails!\ Use\ vector\ addition\ instead}$$
